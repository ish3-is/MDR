# MADAR V3 ELITE — مدار

موقع مؤسسي عربي أولًا، مع نسخة إنجليزية كاملة. نسخة V2 والأصول الأصلية بقيت دون تعديل؛ المشروع الجديد مستقل داخل `madar-v3-elite`.

الموقع المنشور: **https://ish3-is.github.io/MDR/** — المستودع: **https://github.com/ish3-is/MDR**. ينشر GitHub Actions التعديلات المدفوعة إلى `main` تلقائيًا بعد اجتياز الفحوص. تفاصيل النشر في [سجل النشر](docs/DEPLOYMENT.md).

## التشغيل

يتطلب Node.js 24 LTS وnpm. لا توجد قاعدة بيانات أو مفاتيح API أو خدمة خلفية.

```powershell
cd D:\MDR\MDR-STORE\madar-v3-elite
npm ci
npm run dev
```

افتح الرابط المحلي الذي يظهر. لبناء ومعاينة نسخة الإنتاج:

```powershell
npm run build
npm run preview
```

`dist` هو المجلد القابل للنشر، وليس مجلد المصدر. افتحه عبر خادم HTTP؛ الفتح المباشر بـ `file://` غير مدعوم.

## ما تتضمنه النسخة

- 34 صفحة بالعربية و34 بالإنجليزية: الرئيسية، التعريف، الخدمات، 11 صفحة خدمة، الأعمال، 13 صفحة مشروع، الأكاديمية، البحث، الفريق، التواصل، الخصوصية والشروط.
- روابط حقيقية مع توليد HTML لكل صفحة. يعمل تحديث صفحات التفاصيل على الاستضافة الثابتة دون SPA fallback. يوجد مسار متوافق مع V2 باسم `/portfolio` وصفحات 404.
- فيلم مدار الأصلي، تشغيل صامت دون تكرار إجباري، زر إيقاف وتشغيل، تحويل WebM إلى MP4 عند فشل فك الترميز، وملصق بديل. تُحترم الحركة المخففة وتوفير البيانات.
- بحث وفلاتر مشاريع قابلة للمشاركة في الرابط، معاينة اللقطات الأصلية، تصفية المساهمين، قائمة خدمات وقائمة هاتف تدعمان لوحة المفاتيح.
- نموذج طلب عرض سعر يتحقق من المدخلات والموافقة، ثم يتيح مراجعة رسالة قبل فتح واتساب أو البريد. لا يخزن الطلب ولا يدّعي استلامه.
- خطوط محلية، بيانات وصفية لكل صفحة، Open Graph، دعم canonical وhreflang، وsitemap عند تحديد عنوان النشر الحقيقي.

## النشر على GitHub Pages

ارفع **محتويات هذا المجلد** إلى جذر المستودع الذي تختاره. من Settings → Pages اختر GitHub Actions. ملف `.github/workflows/deploy.yml` يثبت الحزم من ملف القفل، ويشغّل الاختبارات والبناء وفحص الروابط الداخلية، ثم ينشر `dist`.

رُفع المشروع إلى مستودع `ish3-is/MDR` بطلب المستخدم، وفُعّل GitHub Pages باستخدام GitHub Actions وHTTPS. التحديثات اللاحقة تكون بالدفع إلى `main`.

يستنتج Workflow مسار المستودع والنطاق من إعدادات Pages. للبناء اليدوي، استخدم عنوان الموقع **الكامل مع مسار المستودع**، دون شرطة نهائية:

```powershell
$env:VITE_BASE_PATH = '/repository-name/'
$env:VITE_SITE_URL = 'https://your-account.github.io/repository-name'
npm run build
node scripts/verify-build.mjs
Remove-Item Env:VITE_BASE_PATH,Env:VITE_SITE_URL
```

عند نطاق مخصص في الجذر استخدم `VITE_BASE_PATH='/'` و`VITE_SITE_URL='https://your-domain.tld'`. أضف ملف `public/CNAME` باسم نطاقك فقط عند امتلاكه. لا يوجد نطاق مفترض في المصدر.

البناء المحلي دون `VITE_SITE_URL` لا يختلق عنوان canonical؛ يكون sitemap فارغًا إلى أن يُحدد عنوان حقيقي. لا تعتمد على رابط يحوي `#` لفهرسة الصفحات.

## التحقق

```powershell
npm test
npm run typecheck
npm run build
node scripts/verify-build.mjs
npm run test:e2e
npm audit
```

اختبارات المتصفح تستخدم Edge المثبت في Windows. على نظام آخر ثبّت Chromium عبر `npx playwright install chromium` واضبط `QA_BROWSER=chromium`. لا يُرسل اختبار النموذج رسالة فعلية.

لأدوات Lighthouse افتح نسخة الإنتاج على المنفذ 4180 ثم شغّل `node scripts/lighthouse.mjs`. تدعم الأداة Edge على Windows، أو مسار متصفح عبر `CHROME_PATH` عند تهيئته. النتائج الفعلية وقيودها في [تقرير التسليم](docs/DELIVERY.md)، والتقارير والصور في `docs/qa`.

لا يوجد إعداد ESLint موروث أو مضاف؛ لا ندّعي اجتياز فحص lint غير موجود. يستخدم المشروع TypeScript strict، اختبارات Node، Playwright وaxe.

## البنية والتعديل

```text
src/content/       المشاريع والخدمات والفريق، بأنواع عربية/إنجليزية
src/components/    التنقل والبطاقات والفيديو والنموذج والعناصر المشتركة
src/pages/         الصفحات وتجارب المكتبة والتفاصيل
src/i18n/          سياق اللغة ومسارات التنقل
src/lib/           التحقق ورسائل التواصل والبيانات الوصفية
src/styles/        المتغيرات البصرية والتنسيق المتجاوب
scripts/           البناء المسبق والتحقق والجرد وقياس الأداء
tests/             اختبارات المدخلات والتفاعلات والمتصفح
public/            العلامة والفيديو واللقطات والخطوط
docs/              فحص V2 والمصادر والجرد والتسليم ونتائج QA
```

أضف النصين العربي والإنجليزي إلى كل سجل. صفحات تفاصيل المشاريع والخدمات تُولد تلقائيًا من السجلات. الخط العرضي المضغوط يحتوي حروف الشعار النصي والأفاتارات الحالية؛ عند تغيير عباراتها أعد توليد مجموعته الفرعية أو استخدم ملف OTF الكامل المرفق. بيانات ترخيص الخط العرضي لم تُرفق؛ راجع `docs/ASSETS.md` قبل النشر العام.

## حدود المحتوى

مدار مبادرة قيد التأسيس وليست منشأة تجارية مسجلة أو جهة اعتماد حاليًا. لا توجد شهادات عملاء أو شركاء مفترضون. رقم 135 مرتبط فقط بالمعسكر السابق ومدته أسبوع وفق بيانات الفريق. حالة البحث ونسبة المشاركة غير مفترضة، وملفات المرشحين غير المؤكدة مستبعدة. قائمة النواقص في تقرير التسليم.
