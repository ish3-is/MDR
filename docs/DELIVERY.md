# تقرير تسليم MADAR V3 ELITE

التاريخ: 22 أكتوبر 2026 — بتوقيت المملكة العربية السعودية.

## النسخة المسلّمة

المشروع الكامل في `madar-v3-elite`، مستقل عن V2 التي بقيت دون تعديل. ملفات المصدر والبناء وملف القفل وإعداد النشر والاختبارات والوثائق مرفقة في الحزمة النهائية `MADAR-V3-ELITE.zip`. لم يتم نشر أي موقع أو تعديل مستودع بعيد.

## ما تغير فعليًا

- إعادة بناء التكوين البصري والمكوّنات: كحلي عميق ومساحات لؤلؤية، تدرج خطي متجاوب، فواصل تحريرية، ولمسات بنفسجية وذهبية محدودة. الشعار الأصلي محفوظ ببصمة مطابقة؛ لا توجد هوية بديلة.
- الصفحة الرئيسية تتبع التسلسل المطلوب: فيديو، خبرات، مشاريع مختارة، خدمات، أسباب الاختيار، بحث، أكاديمية، المؤسسون الثلاثة بالتساوي، منهجية عمل، طلب سعر وتذييل.
- 68 صفحة محلية اللغة: 34 بالعربية و34 بالإنجليزية، تشمل تفاصيل 11 خدمة و13 مشروعًا، مع روابط نظيفة وتوليد HTML مسبق. ينتج البناء 73 ملف HTML عند احتساب مساري V2 وصفحتي 404 وملف `404.html` الخاص بالاستضافة.
- مكتبة مشاريع ببحث في اللغتين والتقنيات، وفلاتر مجال ومشاريع مختارة تُحفظ في الرابط. تفاصيل المشروع تعرض السياق والتحدي والمنهج والقدرات والمراجع والحدود ونسبة المساهمة. يمكن تكبير اللقطات الحقيقية في نافذة تدعم لوحة المفاتيح.
- فيديو مدار الأصلي 12 ثانية، صامت ودون حلقة إجبارية. يبدأ بعد أولوية عرض النص والخطوط، ويتوقف خارج الشاشة أو عند إخفاء الصفحة. عند فشل WebM ينتقل إلى MP4 ثم إلى الملصق عند تعذر كليهما. لا ينزل الفيديو تلقائيًا مع تفضيل تقليل الحركة أو توفير البيانات.
- كتالوج خدمات مع مخرجات وجمهور ومنهج وأمثلة وأسئلة وأزرار طلب سعر مسبقة الاختيار. الخدمات الأكاديمية مقتصرة على التعليم والإرشاد والمراجعة.
- مسار عرض السعر: تحقق من الاسم والتواصل والخدمة والوصف والمدة والموافقة، ميزانية اختيارية، معاينة نصية ثم رابط واتساب مرمّز أو بريد. لا يوجد إرسال صوري إلى خادم، ولا تخزين محلي لبيانات الطلب.
- صفحات أكاديمية وبحث وفريق وخصوصية وشروط. فلاتر للمساهمين، أفاتارات هندسية، واستبعاد المرشحين غير المؤكدين والبيانات الشخصية غير المصرح بها.
- بيانات وصفية مخصصة، Open Graph وhreflang وcanonical وsitemap حسب عنوان النشر. البيانات المنظمة من نوع WebSite فقط؛ لا تسجيل تجاري أو شراكات أو جوائز مفترضة.
- محتوى مكتوب باللغتين، RTL/LTR، خطوط ووسائط محلية، مؤشرات تركيز مرئية، نوافذ بحصر وإعادة التركيز، دعم Escape وskip link، وحركة مخففة.

## قياس Lighthouse المحلي

على نسخة الإنتاج في Edge، بمضاهاة الهاتف وشبكة/معالج Lighthouse الافتراضيين، وسطح مكتب 1440×1000:

| الفئة          | الهاتف | سطح المكتب |
| -------------- | -----: | ---------: |
| الأداء         |     90 |        100 |
| الوصول         |    100 |        100 |
| أفضل الممارسات |    100 |        100 |
| SEO            |    100 |        100 |

القياس المحلي للهاتف: FCP نحو 2.5 ثانية، LCP نحو 3.1 ثانية، TBT نحو 60ms، وCLS نحو 0.024. سطح المكتب: LCP نحو 0.7 ثانية وCLS نحو 0.005. هذه نتائج قياس محلي وليست ضمانًا لنتيجة مماثلة بعد النشر؛ تتأثر الاستضافة والجهاز والشبكة. التقارير الأصلية HTML وJSON مرفقة. بقي اقتراح غير حرج لتقليل JavaScript غير المستخدم؛ لم تُضف مكتبة حركة أو خادم لتضخيم الاعتماديات.

تحسينات مرتبطة بالقياس: ملصق 23.8KB بدل 66.3KB للعرض، شعار 15.1KB للواجهة مع حفظ الأصل، وخط عرض WOFF2 فرعي 34.8KB بدل OTF بحجم 285.2KB. الأنماط مضمنة في HTML الإنتاج لتقليل الطلبات الحاجبة للرسم.

## النواقص والقيود الموثقة

1. **حقوق الخط العرضي:** ملف OTF مقدم من المستخدم وتظهر بيانات HadiType داخله، لكن لم ترفق وثيقة ترخيص. يجب تأكيد حق استخدامه على الويب والنشر العام أو استبداله بخط IBM Plex المتاح. لا يُدّعى امتلاك ترخيص غير مقدم.
2. **ميزان:** الدليل المتاح لقطة محلية تتضمن خطأ طلب. لا مستودع أو عرض حي أو تقنيات أو نتائج تشغيلية موثقة؛ لم تُختلق.
3. **R-M وProject:** README مقتضب جدًا. **Housing System:** مستودع عام به ملفات دون README. بقيت السجلات محايدة دون اختراع وظائف أو تقنيات. رابطا incident وZabbix لم تُنسب لقطاتهما إلى مشروع محدد.
4. **لقطات المشاريع الثلاثة المختارة الأخرى:** لم تُرفق لقطات مستقلة معتمدة؛ استُخدمت رسوم مفاهيمية موسومة بوضوح، وليست لقطات تطبيق مختلقة.
5. **البحث:** لا ورقة منشورة أو رابط رسمي أو نتائج أو موافقات نشر أسماء المشاركين متاحة. العرض لمسار الدراسة فقط، دون افتراض تأييد الجامعة.
6. **الفريق:** الأسماء والتخصصات من الوثيقة، والروابط المهنية السليمة من V2. لا صور شخصية معتمدة؛ الأفاتارات رمزية. التهجئة الإنجليزية قابلة للمراجعة من أصحاب الأسماء. المرشحون التسعة غير المؤكدين مستبعدون.
7. **الروابط المهنية:** GitHub الموروث `Rer-cys` أعاد 404 وأزيل؛ رابط LinkedIn الشخصي محفوظ كما ورد، لكن منع الفحص الآلي برمز 999 ولا يمكن إعلان التحقق منه.
8. **إتاحة الرسائل:** يعتمد الإرسال على تطبيق واتساب أو تطبيق البريد والجهاز والاتصال. يتيح الموقع إعداد الرسالة فقط؛ لا بريد خادمي أو قاعدة بيانات مطلوبة في النطاق.
9. **النشر:** إعداد GitHub Actions جاهز، لكنه لم يُشغّل على مستودع بعيد لعدم وجود إذن نشر. يلزم رفع المشروع للمستودع المختار وتفعيل Pages. canonical وsitemap النهائيان يتولدان بعنوان النشر الحقيقي؛ بناء الجذر المحلي لا يختلق عنوانًا.
10. **التغطية البشرية:** الاختبارات الآلية ولقطات سطح المكتب والهاتف فُحصت، لكن لم يُختبر Safari/iOS أو قارئ شاشة فعلي أو جهاز هاتف مادي. لم تُجرَ اختبارات اختراق أو تحقق تشغيلي مستقل من المشاريع المعروضة.

## ما يلزم للتشغيل والنشر

التشغيل المحلي: `npm ci` ثم `npm run dev`. للنشر ارفع محتويات مجلد المشروع إلى جذر مستودعك واتبع README، أو انشر `dist` على استضافة ثابتة بعد ضبط المسار والعنوان. راجع حقوق الخط والملاحظات المحتوائية قبل النشر العام.
