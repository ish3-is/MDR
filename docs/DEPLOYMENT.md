# نشر GitHub Pages

طلب المستخدم الرفع والنشر على المستودع المحدد في 22 أكتوبر 2026.

- المستودع: https://github.com/ish3-is/MDR
- الفرع: `main`
- مسار البناء: `/MDR/`
- عنوان النشر: `https://ish3-is.github.io/MDR/`
- آلية النشر: GitHub Actions، باستخدام `.github/workflows/deploy.yml`.

المستودع كان فارغًا قبل الرفع. المصادقة عبر حساب `ish3-is` المحفوظ في Git؛ لا مفاتيح أو رموز وصول مضمنة في المصدر. اللقطات التي لم تُنسب إلى مشروع ومراجع README الخام محفوظة محليًا خارج تتبع Git.

يحدد Workflow عنوان الموقع ومسار المستودع تلقائيًا من إعدادات Pages، ويشغّل اختبارات المدخلات وفحص TypeScript والبناء وفحص المراجع الداخلية قبل النشر. تبقى نتائج الأداء والاختبارات السابقة في `docs/qa`، وملاحظات ترخيص الخط وتوثيق المشاريع في تقرير التسليم.

نجح النشر الأول عبر GitHub Actions: https://github.com/ish3-is/MDR/actions/runs/39688297207

جرى التحقق من الموقع العام: 68 صفحة أعادت HTTP 200 باللغتين، و11 أصلًا عامًا بما فيها الفيديو والخط، وبيانات canonical واللغة، وsitemap يتضمن 68 عنوانًا. سجل الفحص الكامل في `docs/qa/deployment-verification.json`.

فُحص تبديل اللغة والبحث في المشاريع وفتح تفاصيل مشروع وتحديثه من المتصفح على الموقع المنشور. جُددت اختبارات المتصفح المحلية ونجحت 14/14. هذه الحالة تحل محل ملاحظة عدم النشر في تقرير التسليم الأولي.
